# 🤖 ดาวGM — บอทโลกสวมบทบาท

บอทดิสคอร์ดสำหรับเล่นบทบาทในโลก **ดาว GM (Galactic Meridian)** — กาแล็กซีอารยธรรมข้ามจักรวาล

## คุณสมบัติหลัก
- ✅ ทุกคนเริ่มที่ **ด่านตรวจคนเข้าเมือง**
- ✅ เงินเริ่มต้น **100 GM เครดิต**
- ✅ ข้อมูลโลกครบถ้วน: ตระกูล 5 ตระกูล, ยานพาหนะ, สัตว์คู่หู, สนามอารีน่า, กฎหมาย
- ✅ ระบบคำสั่งแบบ Slash Commands
- ✅ เก็บข้อมูลผู้เล่นอัตโนมัติ

## ติดตั้งและใช้งาน
```bash
# ติดตั้ง
git clone https://github.com/bestloveant001-beep/ดาวGM.git
cd ดาวGM
npm install

# ตั้งค่า
cp .env.example .env
# แก้ไขไฟล์ .env ใส่โทเค่นบอท

# รัน
npm start
